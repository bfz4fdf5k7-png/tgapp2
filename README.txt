OrdersPayX — массовая рассылка Telegram

Что умеет:
- Сохраняет user_id после /start.
- Отправляет подписчикам текст, фото, видео и документы.
- Админ готовит рассылку через /broadcast, проверяет её и подтверждает /send.
- /cancel отменяет подготовленную рассылку.
- /stop отключает подписчика от рассылок; /start включает снова.
- Пользователи, заблокировавшие бота, автоматически отключаются.

Установка:
1. Установи Python 3.10+.
2. В терминале выполни:
   pip install -r requirements.txt
3. Создай бота через @BotFather и скопируй токен.
4. Узнай свой Telegram ID через надёжного бота для просмотра ID.
5. Задай переменные окружения:
   BOT_TOKEN = токен бота
   ADMIN_ID = твой числовой Telegram ID
   (не публикуй токен и не вставляй его в HTML/публичный GitHub).
6. Запусти:
   python bot.py

Windows PowerShell:
   $env:BOT_TOKEN="ТОКЕН"
   $env:ADMIN_ID="ТВОЙ_ID"
   python bot.py

macOS/Linux:
   export BOT_TOKEN="ТОКЕН"
   export ADMIN_ID="ТВОЙ_ID"
   python bot.py

Как пользоваться:
- Пользователь должен сам открыть бота и нажать Start (/start).
- В личном чате с ботом отправь /broadcast.
- Следующим сообщением отправь текст или медиа.
- Бот покажет подготовленное сообщение; отправь /send для подтверждения или /cancel для отмены.

Важно:
- Telegram не позволяет боту писать людям, которые никогда не запускали его.
- Используй рассылку только для пользователей, согласившихся получать уведомления.
- Бот должен постоянно работать на сервере/хостинге, иначе рассылка не выполнится.
- База SQLite orderspayx_users.db создаётся автоматически в папке запуска.
- Это отдельный Python-бот backend; сам HTML Mini App не может безопасно хранить токен или выполнять рассылку.
